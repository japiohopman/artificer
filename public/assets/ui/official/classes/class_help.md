# Class & Calling Help

Your class determines how your character interacts with combat, exploration, and problem solving.

---

### Roles Overview
* **Martial Classes (Fighter, Barbarian, Paladin, Monk):** Excel in direct combat and front-line toughness.
* **Spellcasters (Wizard, Sorcerer, Cleric, Druid, Warlock):** Channel powerful arcane or divine magic.
* **Versatile Specialists (Rogue, Ranger, Bard):** Combine skills, mobility, and support or stealth.
