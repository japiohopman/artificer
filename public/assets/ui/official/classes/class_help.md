# Class Mechanics Guide

Classes dictate your combat capabilities, Hit Dice, saving throw proficiencies, and progression milestones.

### Key Class Elements
1. **Hit Die:** Determines maximum hit points gained per level (e.g., d6 for Wizards, d8 for Clerics/Rogues, d10 for Fighters, d12 for Barbarians).
2. **Saving Throws:** Each class grants proficiency in two saving throws (e.g., Strength & Constitution for Fighters; Intelligence & Wisdom for Wizards).
3. **Spellcasting:**
   - **Intelligence:** Wizards, Artificers
   - **Wisdom:** Clerics, Druids, Rangers
   - **Charisma:** Bards, Paladins, Sorcerers, Warlocks
4. **Proficiencies:** Defines which weapons, armor types, and skill proficiencies your hero can utilize effectively.
