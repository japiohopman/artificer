# Equipment Sprite Sheets Master Manifest & Layout Specifications

This directory contains complete visual 4×4 grid sprite layout specifications for ALL starter equipment sprite sheets.

## Grid Specifications
- **Grid Layout**: 4 columns × 4 rows (16 cells per spritesheet)
- **Cell Size**: 256 × 256 pixels
- **Recommended Canvas Size**: 1024 × 1024 pixels
- **File Format**: Transparent WebP or PNG with alpha channel
- **Formula**: `Row = Math.floor(cell_index / 4)`, `Col = cell_index % 4`
